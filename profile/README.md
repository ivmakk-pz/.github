# Project Zomboid mods by ivmakk

Open-source Build 42 mods for *Project Zomboid*. Each mod is free on the Steam Workshop, and its source code is here.

## Mods

| Mod | What it does | Version | Download |
|---|---|---|---|
| [Foraging Tooltip Extended](https://github.com/ivmakk-pz/pz-foraging-tooltip-extended) | A detailed foraging tooltip that breaks down every modifier affecting your search radius. | 2.2.4 | [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3507997225) |
| [Milk Them All](https://github.com/ivmakk-pz/pz-milk-them-all) | Milking QoL: quicker with your Animal Care skill, auto-sit, less container juggling, and a yield preview so you know who's worth milking. | 1.3.3 | [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3568280195) |
| [Quick Forage Icon Discard](https://github.com/ivmakk-pz/pz-quick-forage-icon-discard) | One-click discard for foraged items - faster foraging without the context menu. | 1.4.2 | [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3593442524) |
| [Restore Engine Quality](https://github.com/ivmakk-pz/pz-restore-engine-quality) | Restore your vehicle's engine quality with a Wrench, Spare Engine Parts, and Mechanical skill 4+ | 1.2.3 | [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3543612325) |

## Install

Subscribe to a mod on the Steam Workshop, then turn it on in the **Mods** menu of the game.

## Bugs and ideas

Open an issue in the repo of the mod, or post on its mod page. For a bug, add your game version and the log file: `console.txt` in `%USERPROFILE%\Zomboid`.
